## Context

当前俄罗斯方块游戏已经完成核心功能，包括方块移动、旋转、消行、计分等。现在需要添加音效来增强游戏体验。游戏运行在 Windows 终端，使用 Windows Console API 渲染。

## Goals / Non-Goals

**Goals:**

- 为游戏操作提供听觉反馈
- 使用纯代码生成音效，无需外部音频文件
- 支持静音/取消静音功能
- 音效播放不阻塞游戏主循环

**Non-Goals:**

- 不支持自定义音效
- 不支持背景音乐
- 不支持音量调节

## Decisions

### 1. 使用 Windows Beep API

**选择**: 使用 `Beep()` 函数生成音效

**理由**:
- 无需外部依赖
- 无需加载音频文件
- 可以通过频率和持续时间控制音调

**替代方案**:
- `MessageBeep()`: 只能播放预定义的系统声音，不够灵活
- 外部音频库（如 SDL_mixer）: 增加依赖复杂度

### 2. 异步播放音效

**选择**: 在单独的线程中播放音效

**理由**:
- `Beep()` 是阻塞调用，会暂停当前线程
- 游戏主循环不能被阻塞
- 使用 `std::thread` 简单实现

### 3. 音效配置

**选择**: 使用枚举定义音效类型，集中管理音效参数

**理由**:
- 易于维护和修改
- 类型安全
- 集中管理频率和持续时间

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|----------|
| Beep() 在某些系统上可能不工作 | 提供静音选项作为后备 |
| 多线程播放可能导致声音重叠 | 使用简单的互斥锁控制 |
| 音效可能影响游戏性能 | 异步播放，不阻塞主线程 |

## Open Questions

- 是否需要支持音量调节？（当前设计不支持）
- 是否需要在游戏设置中添加音效开关？（当前使用按键切换）
